# Sthanam — Brand Guidelines

## 1. Brand Identity
- **Name**: Sthanam
- **Origin & Meaning**: Derived from Sanskrit / Marathi **"sthān" (स्थान) / "sthanam"**, meaning a place, designated spot, sacred ground, or sanctuary. In the context of the platform, it signifies finding one's designated, verified parking space amidst the high-density crowds and sacred journeys in Nashik.
- **Tagline**: Nashik–Trimbakeshwar Ghat Mobility
- **Event Scope**: Smart parking for Nashik, Maharashtra (Kumbh Mela 2027 + everyday urban mobility).

## 2. Logo Rules
- **Monogram**: Single, clean capital **"S"** monogram centered in a rounded square (`rounded-lg` / `rounded-xl`, radius ~25%).
- **Base Tile**: Deep Highway/Forest Green (`#006B4F` / `#005A36`).
- **Typography**: Clean, bold sans-serif/monospace font (`font-mono font-black`).
- **Status Indicator**: An amber-gold status dot (`#E9A83A` with border) positioned at the edge, representing real-time telemetry and verified space availability.
- **Header Lockup**: Accompanied by the brand wordmark **"Sthanam"**, an event badge (`2027`), and the subline `"Nashik–Trimbakeshwar Ghat Mobility"`.
- **Favicon**: SVG rendering of the green square with "S" monogram and the gold status dot.

## 3. Core Color Palette
| Token / Name | Hex | Usage |
| :--- | :--- | :--- |
| **Forest Green (Primary Brand)** | `#006B4F` / `#005A36` | Main brand badge, primary CTAs, active highlights |

| **Sacred Crimson** | `#8B2E21` | Admin telemetry, high-priority notifications, heritage stubs |
| **Heritage Cream** | `#FAF7F2` / `#FAF6EE` | App background, ticket paper texture, cards |
| **Sage / Line** | `#E2DDD3` / `#E8E4DA` | Subtle dividing lines, borders, card outlines |

## 4. Brand vs. Event Context
- **Brand (Use "Sthanam")**: Global header, nav bar, page titles, digital parking ticket headers, QR scanner and plaque titles, admin control center title, demo modals, footer copyright.
- **Event Context (Keep Unchanged)**: Historical event descriptions such as *"Kumbh Mela 2027"*, *"Maha Kumbh Mela 2027"*, *"Kumbh journey"*, zone names, and geographic landmarks.
